# Contributing

```bash
uv sync --all-extras
uv run pre-commit install        # ruff, ruff format, mypy on every commit
uv run pytest --cov              # must stay above 90% branch coverage
```

## Postgres tests

`tests/test_postgres.py` runs the demo scenario against a real Postgres when `SYNCLINE_TEST_PG_URL` is set
(CI sets it). Locally:

```bash
docker run -d --name syncline-pg -e POSTGRES_PASSWORD=postgres -p 55432:5432 postgres:16-alpine
SYNCLINE_TEST_PG_URL=postgresql+psycopg://postgres:postgres@localhost:55432/postgres uv run pytest
```

## Conventions

- Problems with the data are **results** (rejected rows, run statuses), not exceptions.
  Problems with configuration, sources and targets raise one of `SpecError`, `SourceError`,
  `MappingError`, `TargetError`, before anything is written.
- Messages are written for the person who has to fix the file: what is wrong, where, and what was expected.
- Example data is generated by `scripts/make_examples.py` (seeded, deterministic). Every person and company
  in it is fictional.
- `docs/demo.gif` is rebuilt from real output with `scripts/make_demo.py`; don't edit frames by hand.
